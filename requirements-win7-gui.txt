# GUI 依赖 —— **这是 GUI 的主路径**（Python 3.8 + PySide2 / Qt 5.15）
#
# 2026-09-16 定案：GUI 绑定收敛到 PySide2（开发与交付同一个环境）。
#   原 requirements-gui.txt（PySide6 / Qt 6）已标为遗留分支。
#
# 为什么不是 PySide6：
#   Qt 6 官方只支持 Windows 10 (1809+) / Windows 11，不支持 Win7。
#   PySide2 = Qt 5.15，Win7 → Win11 都能跑。
#   PySide2-Fluent-Widgets 与 PySide6 版是同一作者、同一套 API，
#   所以 gui/app.py 只需换 import，界面代码不用重写。
#
# ⚠️ PySide2 5.15.2.1 的 requires_python 是 <3.11 ——
#    它**装不进 Python 3.11+ 的环境**。本机用仓库内的便携工具链：
#        .toolchain\py38\python.exe -m pip install -r requirements-win7-gui.txt
#
# 许可证：安装包标注 GPLv3，本项目按 GPLv3 分发并提供对应源码。
# GPLv3 本身允许商用；Fluent 作者另有商业授权说明，商业场景须核实。
# 详见 LICENSE 和 licenses/THIRD_PARTY_NOTICES.md。
#
# ⚠️ 不要与 PyQt-Fluent-Widgets / PyQt6-… / PySide6-… 同时安装，
#    它们的模块名都是 qfluentwidgets。

# Qt 绑定。5.15.2.1 是 PySide2 的最后一个版本，有 cp38 win_amd64 / win32 wheel。
PySide2==5.15.2.1
PySide2-Fluent-Widgets>=1.11.3
